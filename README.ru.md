## 🧑‍💻 О себе

- 🏛️ Тестирую портал **mos.ru**
- 🔍 Прохожу весь путь от требований до автотестов: тест-дизайн, ручные проверки, UI и API автоматизация
- 📋 Веду тест-кейсы в **Allure TestOps** и связываю их с автотестами (Jira → TestOps → код)
- 🚀 Запускаю тесты в CI на **Jenkins** с отчётами в Allure

## 🤖 AI в тестировании

Использую AI-агентов как инженерный инструмент, а не просто как чат.

- Проектирую **мультиагентный QA-процесс** на Claude Code: отдельные агенты для тест-дизайна, написания автотестов по тест-кейсам из TestOps и разбора падений
- Подключаю агентов к рабочим инструментам через **MCP**: Allure TestOps, Jira, Confluence — по умолчанию только чтение, любую публикацию подтверждает человек
- Делаю конфигурацию независимой от среды, чтобы она работала в Claude Code, Cursor и Codex CLI
